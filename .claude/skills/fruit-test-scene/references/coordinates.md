# 좌표와 모양 규칙

## 세 가지 방향 체계

| 체계 | 축 | 어디서 |
|---|---|---|
| 세계(WebXR) | x 오른쪽, **y 위**, z 뒤쪽. 단위 m. 테이블 면은 `y = tableY` | AR 위치, 테이블 면 위 점, 과일 중심 |
| WebXR 카메라 | x 오른쪽, y 위, **-z 앞**(카메라가 보는 방향) | `view.transform.matrix`(카메라 → 세계, 열 우선 4x4) |
| 사진 방향 | x 오른쪽, **y 아래**, **z 앞** | `pixelToRay(p, k) = [(x - cx)/fx, (y - cy)/fy, 1]` |

- 사진 방향 → 세계: `cameraDirToWorld(matrix, v)`는 `[v0, -v1, -v2]`로 바꾼 뒤 회전만 적용한다.
- 세계 → 사진 방향: `worldDirToCamera(matrix, v)`는 회전의 전치를 적용한 뒤 `[c0, -c1, -c2]`로 바꾼다.
- 행렬은 열 우선이다: 위치는 `m[12], m[13], m[14]`, 회전 열은 `m[0..2]`, `m[4..6]`, `m[8..10]`.
- 테스트의 `cameraPose(position, pitchDeg)`는 아래를 `pitchDeg`만큼 내려다보는 카메라다. 90이면 바로 아래를 본다.

## 구의 윤곽(원뿔)

- 카메라에서 구를 보면 윤곽을 지나는 시선은 모두 「카메라 → 중심」 축과 같은 각도 α를 이룬다.
- 중심까지 거리 = 반지름 / sin α. 사진 속 위치와 상관없이 성립한다.
- 시선 u마다 `u·d = cos α`이므로 `w = d / cos α`로 두면 `u·w = 1`인 일차식이 되어 최소제곱으로 푼다(`fitCone`).
- AR: 테이블 위 구의 중심 높이는 `tableY + r`이므로 `r = H / (1 - d_y / sin α)`(H는 카메라 높이, d_y는 축의 위쪽 성분)로 바로 구한다(`measureFruitCone`).

## 회전타원체(가로 반지름 a, 세로 반지름 c)

- 세로축은 세계 y(테이블에 수직)로 본다. 중심 높이는 `tableY + c`다.
- **늘리기**: 테이블 면을 기준으로 y만 `s = a / c`배 늘리면 반지름 a인 구가 되고, 그 구도 테이블에 놓인다.
  - 점: `stretchPoint(p, s, tableY) = [x, tableY + (y - tableY)·s, z]`, 되돌리기는 `1/s`
  - 방향: `stretchDir(v, s) = normalize([vx, vy·s, vz])`
  - 늘려도 직선은 직선, 접하는 선은 접하는 선이다. 그래서 늘린 공간에서는 구의 계산을 그대로 쓰고 결과만 되돌린다.
- **비율 찾기**: 비율을 바꿔 가며 늘린 시선들이 원뿔에 가장 잘 맞는 값을 찾는다(`searchSpheroidRatio`, 세로/가로 0.5~1.5).
- **구분 가능성**: 시선이 수직(바로 위)에 가까울수록 세로가 윤곽에 드러나지 않는다. 수직에서 30°보다 덜 기울면 비율에 따른 맞춤 오차 차이가 화소 1개 수준이라, 앱은 이 경우 더 눕히라고 안내한다(`viewTiltDeg`).
- **표면까지 거리**: 카메라에서 중심을 향한 단위 방향 w에 대해, 중심에서 표면까지 길이는
  `1 / sqrt((wx² + wz²)/a² + wy²/c²)`(`spheroidRadiusAlong`). 표면까지 거리 = 중심까지 거리 - 이 길이.
- 가로=세로(s = 1)이면 모든 계산이 구의 결과와 같아야 한다.
