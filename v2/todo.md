# fruit-measure 2차 Todo

- 2차 PRD는 [`PRD.md`](PRD.md), 1차 PRD·Todo는 [`../PRD.md`](../PRD.md), [`../todo.md`](../todo.md)다.
- `PRD #4-1`은 2차 PRD, `1차 PRD #4-4`는 1차 PRD 항목이다. `1차 5-7`은 1차 Todo 항목을 이어받는다는 뜻이다.
- 할 일 번호(`단계-순번`)로 작업을 지목한다.
- 단계가 끝날 때마다 확인하고 commit·push한 뒤 다음 단계로 넘어간다.
- 완료한 항목은 `[ ]`를 `[x]`로 바꾼다. 진행하며 발견한 버그는 `[버그 수정]` 항목으로 바로 추가한다.

- `[회귀 테스트]`는 앞 단계에서 통과한 테스트를 다시 확인하는 항목이다.

## 7단계: 과일 윤곽 자동 인식

목표: AR 조준점이나 사진 터치로 과일을 가리키면 윤곽을 찾아 크기·거리가 나온다. 윤곽 일부가 끊겨도 구 모양으로 보정한다.

- [x] 7-1. [P1] 경계점 찾기: 가리킨 지점에서 여러 방향으로 선을 뻗어 과일 색과 달라지는 첫 지점 찾기 (PRD #4-5, #7)
- [x] 7-2. [P1] 경계점에 구의 윤곽(원뿔) 맞추기: 원형에 맞지 않는 점(끊김, 그림자, 반사광)은 버리고, 남은 점이 적거나 과일이 사진 밖으로 나가면 실패로 안내 (PRD #4-5, #7)
- [x] 7-3. [P1] 원뿔 각도로 표면까지 거리, 원뿔 방향·각도와 카메라 높이로 크기 계산 (PRD #4-5, #7, 3-2, 4-3)
- [x] 7-4. [P1] AR 화면: 「과일 인식」 버튼, 인식한 과일 둘레를 AR 화면에 표시. 「점 찍기」는 그대로 둠. 크기를 재면 측정 버튼 대신 촬영 버튼만 보임 (PRD #4-1, #4-5)
- [x] 7-5. [P1] 사진 화면: 촬영 직후 가운데에서 자동 인식, 과일을 터치하면 그 지점에서 다시 인식, 찾은 윤곽 표시. 「직접 지정」으로 바꾸면 양 끝 터치 (PRD #4-2, #4-5)
- [x] 7-6. [P1] [테스트] 단위 테스트: 계산으로 그린 구 사진(가운데·가장자리, 잡음, 그림자, 반사광, 윤곽 끊김, 꼭지)에서 거리·크기가 다시 나오는지, 과일이 잘리거나 없는 사진은 실패하는지 확인 (PRD #4-5, #7)
- [x] 7-7. [P1] [테스트] (PC 가짜 WebXR) 과일 인식 → 완료 표시 → 촬영 → 자동 거리 → 저장, 터치로 다시 인식, 직접 지정 전환, 인식 실패 안내 확인 (PRD #4-5)
- [x] 7-8. [P2] [회귀 테스트] 3·4단계 계산식 테스트와 직접 지정 측정이 그대로 되는지 확인 (PRD #4-1, #4-2, 3-5, 4-5)
- [x] 7-9. [P2] [AI 검토] 배포 페이지를 직접 열어 확인 후 보고 (PRD #10)
