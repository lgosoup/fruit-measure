# fruit-measure 2차 Todo

- 2차 PRD는 [`PRD.md`](PRD.md), 1차 PRD·Todo는 [`../PRD.md`](../PRD.md), [`../todo.md`](../todo.md)다.
- `PRD #4-1`은 2차 PRD, `1차 PRD #4-4`는 1차 PRD 항목이다. `1차 5-7`은 1차 Todo 항목을 이어받는다는 뜻이다.
- 할 일 번호(`단계-순번`)로 작업을 지목한다.
- 단계가 끝날 때마다 확인하고 commit·push한 뒤 다음 단계로 넘어간다.
- 완료한 항목은 `[ ]`를 `[x]`로 바꾼다. 진행하며 발견한 버그는 `[버그 수정]` 항목으로 바로 추가한다.
- 우선순위: P1 필수 / P2 중요 / P3 있으면 좋음
- `[회귀 테스트]`는 앞 단계에서 통과한 테스트를 다시 확인하는 항목이다.
- `[폰]`은 AR·카메라처럼 폰 크롬에서만 확인할 수 있는 테스트로, 사용자가 확인한다.

## 3단계: AR 크기 측정

- [ ] 3-1. [P1] 조준점을 과일 끝에 맞추고 「점 찍기」로 두 점 지정, 점과 선 표시 (PRD #4-1, 1차 3-1, 4-1)
- [ ] 3-2. [P1] 두 점 거리와 AR 카메라 높이로 둥근 과일 보정을 적용해 크기(mm) 계산 (PRD #4-1, #7, 1차 4-4)
- [ ] 3-3. [P1] 크기와 그 순간 카메라~과일 표면 거리 표시, 화면 옆 완료 표시, 촬영 버튼은 완료 후에만 활성 (PRD #4-1, #4-2)
- [ ] 3-4. [P2] 크기 다시 재기 (PRD #4-1, 1차 3-3)
- [ ] 3-5. [P1] [테스트] 계산식 단위 테스트: 같은 높이·두 점 거리에서 1차 보정식과 같은 결과인지 확인 (PRD #7, 1차 4-5)
- [ ] 3-6. [P1] [테스트] [폰] 30cm 이상에서 과일 크기를 재 캘리퍼스 값과 비교 (PRD #4-1, #10)
- [ ] 3-7. [P2] [테스트] 같은 위치 두 점, 면을 못 찾은 상태에서 점 찍기, 30cm보다 가까이서 측정, 다시 재기 후 이전 점이 남지 않는지 확인 (PRD #4-1, 1차 3-7, 4-8)
- [ ] 3-8. [P2] [AI 검토] 배포 페이지를 직접 열어 확인 후 보고 (PRD #10)

## 4단계: 사진으로 거리 계산

목표: 완료 표시 뒤 원하는 위치에서 촬영하고, 사진에서 과일 양 끝을 지정하면 표면까지 거리가 나온다.

- [ ] 4-1. [P1] 찍은 사진 두 손가락 확대·이동, 짧은 터치는 점 찍기 (PRD #4-3, 1차 2-4, 2-5, 3-4)
- [ ] 4-2. [P1] 사진에서 과일 양 끝 지정, 점과 선 표시 (PRD #4-2, 1차 4-1)
- [ ] 4-3. [P1] 두 점이 카메라에서 벌어진 각도와 AR 크기로 과일 중심까지 거리를 구하고 반지름을 빼 표면까지 거리(mm) 계산·표시 (PRD #4-2, #7)
- [ ] 4-4. [P2] 다시 찍기(AR 화면으로 돌아가 크기는 유지), 과일 다시 지정 (PRD #4-2)
- [ ] 4-5. [P1] [테스트] 계산식 단위 테스트: 알려진 지름·거리로 만든 두 점에서 거리가 다시 나오는지, 사진 가장자리 쪽 과일도 맞는지 확인 (PRD #4-2, #7)
- [ ] 4-6. [P1] [테스트] PC에서 시험 사진으로 확대·이동·점 찍기와 거리 표시 확인 (PRD #4-2, #4-3)
- [ ] 4-7. [P1] [테스트] [폰] 약 10cm에서 찍어 자로 잰 거리와 비교 (PRD #4-2, #10)
- [ ] 4-8. [P2] [테스트] 같은 위치 두 점, 사진 밖 터치, 확대한 채 연속 터치, 다시 찍기·다시 지정 후 이전 값이 남지 않는지 확인 (PRD #4-2, #4-3)
- [ ] 4-9. [P2] [회귀 테스트] 3단계 계산식 테스트가 그대로 통과하는지 확인 (PRD #4-1, 3-5)
- [ ] 4-10. [P2] [AI 검토] 배포 페이지를 직접 열어 확인 후 보고 (PRD #10)

확인 방법: 약 10cm에서 찍은 사진에서 과일 양 끝을 지정하면 거리(mm)가 보인다.

## 5단계: 기록 저장

목표: 측정 결과가 1차와 같은 목록에 쌓이고, 잘못 잰 기록은 지울 수 있고, 다시 열어도 남아 있다.

- [ ] 5-1. [P1] 측정 결과 저장: 측정 번호, 크기, 거리, 측정 시각. 1차와 같은 저장 공간, 번호는 「가장 큰 번호 + 1」 (PRD #4-4, #7, 1차 5-1, 5-7)
- [ ] 5-2. [P1] 기록 목록 화면: 거리 칸 추가, 1차 기록(거리 없음)은 「–」 (PRD #4-4, 1차 5-2)
- [ ] 5-3. [P2] 기록 삭제: 「삭제」 → 「정말 삭제」 두 번 누르기 (PRD #4-4, 1차 5-6)
- [ ] 5-4. [P1] [테스트] 3번 저장 → 새로고침 → 2번 삭제 → 다음 저장이 4번인지 확인 (PRD #4-4, 1차 5-4, 5-8)
- [ ] 5-5. [P1] [테스트] 1차에서 저장한 기록과 2차 기록이 서로의 목록에 보이고, 한쪽에서 지워도 다른 기록이 망가지지 않는지 확인 (PRD #4-4, #7)
- [ ] 5-6. [P2] [테스트] 저장 연타, 거리 측정 전 저장 시도, 손상된 저장 데이터에서도 오류 없이 동작하는지 확인 (PRD #4-4, 1차 5-10, 5-11)
- [ ] 5-7. [P2] [회귀 테스트] 3·4단계 계산식 테스트와 PC 사진 측정이 그대로 되는지 확인 (PRD #4-1, #4-2, 3-5, 4-5, 4-6)
- [ ] 5-8. [P2] [AI 검토] 배포 페이지를 직접 열어 확인 후 보고 (PRD #10)

확인 방법: 측정 3회 후 다시 열면 1~3번 기록이 보이고, 2번을 지우면 1·3번만 남으며 다음 측정은 4번이 된다.
